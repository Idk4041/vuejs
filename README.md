# vuejs

Een Vue.js todo app met Tailwind CSS.

## Vereisten

- [Node.js](https://nodejs.org/) (versie 20 of hoger)
- npm (zit bij Node.js)
- Git

## Installatie

1. Clone de repository:

   ```bash
   git clone https://github.com/idk4041/vuejs.git
   cd vuejs
   ```

2. Installeer de dependencies (inclusief Tailwind CSS):

   ```bash
   npm install
   ```

3. Start de development server:

   ```bash
   npm run dev
   ```

   Open daarna de link die in de terminal verschijnt (meestal `http://localhost:5173`).
